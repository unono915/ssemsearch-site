# 쌤서치 소개 페이지

선생님을 위한 Windows 교직원 내선 검색 앱 SSemSearch의 공식 사용 안내·다운로드 페이지입니다.

## 구성

- 이름·위치(부서)·내선 검색 체험: 가상 명단만 사용하며 입력을 전송하거나 저장하지 않습니다.
- 3단계 사용 안내, 실제 앱 화면, 빈 엑셀 양식, FAQ
- Windows 설치형·무설치형 다운로드: 이 저장소의 GitHub Releases
- 웹 호스팅: Vercel. GitHub main 변경 시 자동 배포

## 개발과 배포

Node.js 22 이상. 런타임 외 추가 패키지가 없는 정적 사이트입니다.

```sh
npm run dev
# http://127.0.0.1:4173
npm run build
# dist/를 배포합니다.
```

`vercel.json`에서 빌드 명령과 정적 출력 폴더, 응답 보안 헤더를 설정합니다. 실제 교직원 명단·인증 정보는 저장소나 웹에 넣지 마세요.

## 파일 업데이트

1. 새 Windows 실행 파일을 GitHub Release에 업로드합니다.
2. `index.html`의 버전, 파일명, 다운로드 URL과 크기를 수정합니다.
3. `assets/SHA256SUMS.txt`, 사용 안내, 오픈소스 고지를 함께 갱신합니다.
4. `npm run build` 후 검색 체험·안내 탭·모바일 화면·다운로드 주소를 검증합니다.
5. main에 push하면 Vercel이 다시 배포합니다.

이 저장소에는 소개 페이지와 앱 배포 파일이 있습니다. 데스크톱 앱의 개발 소스는 로컬 앱 프로젝트에서 관리합니다. 실행 파일은 코드 서명이 없는 v1.1.0 빌드이며 기관 보안 정책에 따라 실행이 제한될 수 있습니다.
