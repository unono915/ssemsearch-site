# SSemSearch · 쌤서치

필요할 때 이름·교무실·내선을 검색하고 바로 업무로 돌아가는 Windows 로컬 앱입니다. 결과는 눈으로 확인하는 목록이며 클릭·Enter 복사나 전화 연결은 없습니다.

## 시작하기

1. `release`의 `nsis` 설치 파일을 실행하거나 `portable` 실행 파일을 사용합니다. 사용자 계정별로 설치·저장됩니다.
2. 첫 화면에서 **빈 엑셀 템플릿 저장**을 누르거나 기존 `.xlsx` 명단을 선택합니다. 이름·교무실·내선번호 열이 필요합니다.
3. 시트와 머리글 행, 세 열을 확인하고 미리보기에서 오류 및 내선 앞자리 0을 확인합니다.
4. **확인하고 전체 교체**를 누르면 이 PC에 명단을 저장합니다. 이후 원본 Excel 없이 사용합니다.
5. **왼쪽 Alt를 두 번 짧게 누르면** 검색창이 열립니다. 또는 화면의 쌤 아이콘을 클릭합니다. 이름·교무실·내선을 입력하고 번호를 확인한 뒤 **Esc**로 접습니다.

아이콘에 마우스를 올리면 미리보기만 열립니다. 검색창을 클릭하면 입력할 수 있습니다. 아이콘을 드래그해 옮길 수 있고, 검색 중에는 마우스가 벗어나도 닫히지 않습니다. 다른 앱을 클릭하거나 Esc를 누르면 접힙니다. 앱 종료는 트레이 메뉴 또는 설정의 앱 종료입니다.

## 명단과 설정

- 내선은 텍스트로 입력해 `0231` 같은 앞자리 0을 보존하세요. 이미 숫자로 저장되어 잃어버린 0은 앱이 추측해 복원하지 않습니다.
- `.xlsx`, 10MB 이하, 데이터 영역 5,000행·100열 이하. 수식/날짜/오류/병합 셀 및 필수값 누락은 수정 후 가져와야 합니다.
- 동명이인과 공용 내선은 모두 표시합니다. 파일을 다시 가져오면 추가 병합이 아니라 전체 교체입니다.
- 설정에서 파일명·마지막 가져온 날짜와 인원을 확인하고, 단축키 및 Windows 자동 시작을 바꿀 수 있습니다. 자동 시작 기본값은 꺼짐입니다.
- 단축키 변경이 실패하면 기존 설정을 유지합니다. 오른쪽 Alt/한영 키는 기본 호출에 사용하지 않습니다.
- 자동 시작은 설치형 앱을 권장합니다. 이동할 수 있는 portable 실행 파일에서는 경로 변경 후 설정을 다시 저장해야 합니다.

## 저장 위치와 개인정보

기본 저장 위치는 `%APPDATA%\SSemSearch`입니다. `snapshot.json`은 현재 명단, `snapshot.backup.json`은 마지막 정상본, `settings.json`은 설정입니다. 앱은 인터넷 서버에 명단을 전송하지 않으며 검색어나 키 입력 내용을 기록하지 않습니다. 데이터는 평문 JSON이므로 같은 Windows 계정으로 접근할 수 있는 사람은 파일을 읽을 수 있습니다. 제거 시 명단은 자동 삭제하지 않습니다.

## 개발

Node.js 22.12 이상(검증 환경 22.16), Windows x64.

```powershell
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
node scripts/smoke.cjs
npm run package
```

`src/main`은 창/단축키/파일/IPC, `src/preload`는 제한된 API, `src/renderer`는 React UI, `src/shared`는 타입·검색·Alt 판정입니다. UI에 Node 권한이 없으며 명단 파싱은 시간·메모리 제한이 있는 worker에서 수행합니다.

## 확인 범위

실행한 검사와 이 환경에서 확인하지 못한 항목은 `VERIFICATION.md`를 확인하세요. 배포 파일은 코드 서명이 없는 빌드입니다. 개인 서명 인증서는 포함하지 않았습니다. 설치 대상 기관의 정책에 따라 실행이 제한될 수 있습니다.
