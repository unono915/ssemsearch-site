개인정보 처리 안내

시행일: 2026년 10월 6일 · 운영자: Dolgogi

PC에서 처리하는 정보

쌤서치는 사용자가 선택한 엑셀에서 이름, 위치(부서), 내선번호를 읽어 검색 가능한 명단으로 PC에 저장합니다. 파일 이름, 시트 이름, 가져온 날짜와 앱 설정도 저장합니다. 사용자는 명단을 처리할 권한을 확인한 뒤 등록해 주세요.

서버 전송과 키 입력

쌤서치 앱은 명단, 검색어 또는 키 입력 내용을 개발자 서버로 전송하지 않습니다. 광고·사용 분석 도구를 포함하지 않습니다. 단축키를 감지하기 위해 키 이벤트를 처리하지만 키 입력 기록을 저장하지 않습니다.

저장과 삭제

현재 명단과 복구용 백업은 PC에 평문으로 저장됩니다. 같은 Windows 계정에 접근할 수 있는 사람은 파일을 읽을 수 있습니다. 명단을 새로 가져오면 현재 명단을 교체하며 마지막 정상본은 백업으로 남을 수 있습니다. 데스크톱 배포판은 %APPDATA%\SSemSearch를 사용하고, 스토어판은 Windows 패키지 저장 정책에 따라 경로와 제거 동작이 달라질 수 있습니다. 완전한 삭제 방법은 지원 이메일로 문의해 주세요.

외부 AI 안내

앱의 AI 변환 안내는 설명과 복사용 요청문만 제공합니다. 앱이 명단을 AI에 자동 전송하지 않습니다. 사용자가 별도 AI 서비스에 파일을 첨부하면 해당 서비스의 개인정보 처리방침이 적용됩니다. 학교가 허용한 서비스와 자료만 사용하세요.

웹사이트·스토어·고객지원

소개 웹사이트와 파일 다운로드, Microsoft Store 이용에는 각 호스팅·배포 제공자의 정책이 적용됩니다. 지원 이메일을 보내면 회신을 위해 발신 주소와 문의 내용을 사용합니다. 실제 교직원 명단 대신 가상 예시나 개인정보를 가린 화면을 보내 주세요.
